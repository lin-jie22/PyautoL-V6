# ADR：要不要接入「感知模块」（多模态输入 + 语义理解）

- 日期：2026-10-18
- 状态：**分位置判决** —— P0 接（有前置条件）、P1/P2 有条件接、**P3 不接**
- 触发问题：感知模块（视觉 / 语言 / 文本 / 触觉 / 传感器）能否让系统像人一样
  「理解」原始信号，而不是简单分类？

---

## 0. 先钉死「接入」到底指什么

V6 的因果链是：

```
原始输入 → 世界合成器 → 任务(源码 + 判据) → 候选 harness → runner 执行
        → 判定 → reward → 非回归闸 / 泛化闸 → 提交 或 回滚
```

⛔ 关键事实：**V6 现在唯一的「感知」是执行之后的 stdout / exit code / 断言
结果**。它是**真值源**，不是估计。整套系统可信度都建立在这一点上
（README：奖励只来自执行判据）。

⇒ 所以「接感知」不是开一个开关，是**往这条链上的某一个位置插入一个环节**。
不同位置的性质完全不同，把它们混在一起问「该不该接」没有答案。

| 位置 | 感知输出去哪 | 性质 | 判决 |
|---|---|---|---|
| **P0** | 变成**任务与判据**，仍由执行器判对错 | 感知 = 造题器 | ✅ 应该接（过四道闸后） |
| **P1** | 变成可检索的记忆条目 | 感知 = 笔记 | ⚠️ 可接，必须标 `unverified` |
| **P2** | 变成候选变异的建议 | 感知 = 参谋 | ⚠️ 可接，但必须走同一套闸 |
| **P3** | 直接决定对错 / 进 reward | 感知 = 法官 | ❌ **任何条件下都不接** |

---

## 1. 正方：应该接

### 正 1 · 世界的形状被输入通道限死了，而且这是**实测过**的天花板

r47/r48 实证：这台引擎走到第 2 代就不再进化，**不是机器不行，是世界只有 4 个
小函数**。而世界之所以小，是因为只有「能被写成 Python 函数 + JSON 判据」的东西
才能进世界。

视觉、语音、传感器时序、PDF 版面 —— 真实世界的绝大多数信号在**结构上**进不来。
⇒ 现在进化出来的「能力」永远只在「修 Python 源码」这个极窄切片上有意义。
想要能力可迁移，输入通道必须先变宽。

### 正 2 · 「理解」本身需要多模态冗余（符号接地）

纯文本里，「红」这个符号永远只与「红」这个符号相邻；有了视觉，它与一组像素
绑定；有了触觉，「热」与一组温度/痛觉绑定。grounding 靠的是**同一个事实被多个
独立通道各说一次、互相校正**。单通道系统学不到这个 —— 它学到的「理解」永远是
符号之间的统计关系。

### 正 3 · 「分类 vs 理解」的差别，恰恰能被 V6 现有机制检验

- 分类输出的是**标签**（不可独立验证）；
- 理解输出的是**可被独立执行验证的陈述**。

V6 正好有最硬的检验装置：执行判据。⇒ 把感知接进来，要求它的产物**必须编译成
可执行断言**，能不能过 verifier 就是「理解了没有」的可操作定义。这比任何
benchmark 都硬 —— **这是接它的最强理由，也是唯一诚实的接法**。

### 正 4 · 合成负样本的方法论可以照搬

V6 的变异器能做 AST 变异 ⇒ 造得出「坏的」输入。多模态侧只要也能造负样本
（改掉表格里一行、倒放一段音频、在时序里插一个尖峰），就能用同样的方式测
判别力 —— `--min-lethal` 那套闸直接复用。不是从零造方法论。

## 2. 反方：不该接 / 现在不该

### 反 1 · 全部可信度建立在一条纪律上：奖励只来自执行判据

多模态模型的输出是**估计**（概率），不是判据。一旦它进入 reward 或判据链，
整套闸的地基就从「跑出来就是这样」变成「模型说它是这样」。这是 V6 明确拒绝的
reward hacking 形态，而且**最隐蔽**：所有数字都会很好看。

⇒ **P3 不接。这一条没有商量余地。**

### 反 2 · 「理解」没有执行判据 ⇒ 它本身不可验收

能验证的只有「它产出的断言能不能被独立执行证明」。至于它内部是不是真的
「理解」了 —— 那是意向性问题，现有机器学不到也验不了。

⇒ 「像人一样理解原始信号」这个目标**本身不可验收**，必须降级成可验收的形式。
做不到这个降级就接，等于在系统里装一个**无法证伪的部件** —— 与 V5 那个
「死库存 252 个技能」完全同族。

### 反 3 · 现在接入 100% 是投机性 generality

V6 当前的任务**全部**是源码修复。给修 bug 加视觉输入，收益是 0，成本是真实的
（一个新黑箱 + 一条新的不可回归路径 + 一个新的判据漂移源）。

⛔ 第 26 条：**「支持多模态」是规模读数，「在这些模态上真能判别」是强度读数**。
只加规模不加强度 ⇒ 虚胖，只稀释判别力。

### 反 4 · 权重进来了，可回归性就没了

V6 明确「不训练权重」，而多模态编码器就是权重。换一个编码器版本 ⇒ 同一张图
抽出的断言变了 ⇒ 判据集漂移 ⇒ 跨版本不可比。V6 给判据集做内容寻址身份
（`judge.py`）正是为了防这个。

⇒ 接了就必须同时给编码器一套**版本化的内容寻址身份**，否则历史读数一夜全废。

### 反 5 · 假具身：空的读数比没有读数更坏

触觉 / 本体感觉需要实体。没有实体 ⇒ 接进来的是模拟器数据 ⇒ 系统学到的不是
「触摸」，是「触摸数据的分布」。它会给出一个看起来对的读数（「触觉通道正常」），
而那个读数是空的。

⛔ V6 反复踩到这个病：`aging_events["pruned"]` 恒 0、`knowledge.ingested` 0 次
—— **机制在跑，账上看不见它跑没跑**。假具身会把这个病再复制一遍。

## 3. 判决

### 3.1 分位置判（不是一个整体的是/否）

| 位置 | 判决 | 硬约束 |
|---|---|---|
| P0 题源 | ✅ **应该接** | 产物必须是**题面**不是分；编译产物进冻结套件 |
| P1 观测 / 记忆 | ⚠️ 可接 | 显式标 `unverified`；**不许进 reward** |
| P2 提议 | ⚠️ 可接 | 建议必须走现有三道闸，不因「是感知来的」而豁免 |
| P3 判据 / reward | ❌ **不接** | 任何条件下都不接 |

### 3.2 但不现在接 —— 给一个**可测**的触发条件

> 当「源码修复」这条轴被穷尽时才谈扩模态。具体判据：
> `--envs auto`（14 环境）+ 全算子 + `--depth 2` + `--balanced` + `--ho-grow`
> 全开之后，仍然稳定进入 `no_candidates` / `saturated`（连续多轮没有新的能力
> 缺口）。

在那之前扩输入通道，是把「世界太小」这个真问题换成一个**更贵的假问题**
（与第 30 条同源：卡住时先怀疑采样维度，别先换赛道）。

### 3.3 接入前必须过的四道闸（缺一不接）

1. **可合成负样本**：每个模态必须能造出「坏的」输入 ⇒ 否则无从测判别力。
   复用 `--min-lethal` 那套闸（第 37 条：规模必须配强度伴生读数）。
2. **必须能编译成执行判据**：感知的产物是一个**可执行断言集**，不是一个标签。
   编译产物要能进冻结套件（能进 ⇒ 它才受非回归闸保护）。
3. **感知自身的非回归闸 + 内容寻址身份**：编码器版本 = 判据集版本；换版本
   ⇒ 重新发布，跨版本不可比（与 `judge.py` 同源）。
4. **三态分账**：`behavior` / `crash` / `unknown` 分开（第 41 条同源）。
   ⛔ 「感知失败」绝不能并入「感知到了什么」—— 那正是崩溃题冒充行为题的
   同一个病（r50 实测：崩溃题让第 3 代退化成 2 代）。

## 4. 诚实清单：能做到什么，做不到什么

### 能做到

- 多模态信号 → 结构化断言 → 执行判据 的**编译链**，编译产物过现有三道闸；
- 用合成负样本给每个模态配一个「强度」读数（不是只报「支持几个模态」）；
- 感知产物进账本、带内容寻址身份、可回滚、可被闸拦下。

### 做不到（不是努力就能解决的）

- **验证系统「真的理解了」** —— 只能验证它产出的断言能被独立证明。
  意向性不可验收，这一点必须写在目标里，不能含糊过去。
- **触觉 / 本体感觉的真具身** —— 没有实体，接了是模拟器数据，读数是空的。
- **让感知输出充当真值** —— 那会摧毁整套闸的地基（P3 永不接）。

---

## 5. 一句话

> 感知可以接，**但只能当「造题器」接，不能当「法官」接**；
> 而且要在源码这条轴被实测穷尽之后接，不是现在。
> 判断它「理解了」还是「只是分类了」的唯一标准，是它的产物
> **能不能被独立执行验证** —— 这一点，V6 恰好已经有全世界最合适的装置。
